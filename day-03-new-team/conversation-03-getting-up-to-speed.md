# Day 3 · Conversation 3 — Getting Up to Speed

## 🎬 Situation
The team lead shows you the project. Your goal: learn how the team works AND how to start reading the code. Smart questions make you look professional.

## 🗣️ Dialogue — read out loud (both roles), then play the audio and answer

> **Team lead:** Let me show you the project. The code is in our repository, and we use Git for everything.

> **You:** Great. Could you tell me where I should start reading?

> **Team lead:** Start with the main service — it handles all the requests. I'll send you a short document about the system.

> **You:** Thank you. And how does the team organize the work?

> **Team lead:** We work in two-week sprints. Every morning we have a short stand-up, and every Friday we do a demo.

> **You:** That sounds clear. Should I ask questions here or on Slack?

> **Team lead:** Either is fine. We use Slack for quick questions, and the daily stand-up for bigger ones.

> **You:** Got it. I'll start reading the code today.

## 🧠 Your active vocabulary — all words you already know
`project · code · repository · Git · start · reading · main · service · requests · document · system · team · organize · work · sprints · stand-up · demo · questions · Slack · daily · reading`

## ✅ After you speak
- These are the **three smartest first-week questions** — use them at any new job:
  1. **"Where should I start reading?"** (shows you want to learn)
  2. **"How does the team organize the work?"** (shows you care about process)
  3. **"Should I ask questions here or on Slack?"** (shows you respect the team's rules)
- 💡 **"Getting up to speed"** = learning a project quickly. *"It took me a week to get up to speed."*
