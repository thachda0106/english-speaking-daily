# Day 4 · Conversation 2 — Reporting Progress on a Task

## 🎬 Situation
You got your first bug fix. The lead asks about progress. Good progress reports are short and concrete: what you found, what you did, what's next.

## 🗣️ Dialogue — read out loud (both roles), then play the audio and answer

> **Team lead:** Thach, how's the bug fix going?

> **You:** It's going well. Yesterday I found the problem — it was a wrong query in the database layer.

> **Team lead:** Nice. Did you fix it?

> **You:** Almost. I wrote the fix and tested it locally. Today I'll create a pull request and ask for a review.

> **Team lead:** Great, keep it up. Do you need anything from us?

> **You:** Not now, thanks. I'll let you know if I need help with the tests.

## 🧠 Your active vocabulary — all words you already know
`bug fix · going well · found · problem · wrong · query · database · layer · fix · wrote · tested · locally · create · pull request · review · keep it up · need · help · tests`

## ✅ After you speak
- The progress formula = **what you did + what's next**:
  *"Yesterday I found the problem… I wrote the fix and tested it. Today I'll create a pull request."*
- 💡 **"Keep it up."** = keep doing what you're doing (praise). When a lead says it, answer *"Thanks, will do."*
- 💡 **"I'll let you know."** = "I'll tell you when it happens" — a natural promise.
- 🎙️ Play `standup-02`. Then report the progress of YOUR real current task using the formula.
