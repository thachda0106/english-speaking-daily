# Day 4 · Conversation 3 — Being Blocked (the Honest Answer)

## 🎬 Situation
You're stuck. Every developer gets stuck — the skill is saying it OUT LOUD at the stand-up, clearly and without shame. Hiding a blocker is what actually gets you in trouble.

## 🗣️ Dialogue — read out loud (both roles), then play the audio and answer

> **Team lead:** Thach, what's the status of your task?

> **You:** I'm a little stuck, to be honest. The task is bigger than I expected.

> **Team lead:** No problem, that happens. What's the issue?

> **You:** The service works, but I can't run the integration tests on my machine — they need a database setup I don't have.

> **Team lead:** I see. Have you tried the Docker setup in the repository?

> **You:** Not yet. Is that the way we usually do it?

> **Team lead:** Yes, most of us use Docker for the tests. Give it a try, and if it still fails, ask me after the stand-up.

> **You:** Will do, thank you. I'll try it first today.

## 🧠 Your active vocabulary — all words you already know
`status · task · stuck · honest · bigger · expected · problem · happens · issue · service · works · run · integration · tests · machine · database · setup · Docker · repository · usually · try · fails · stand-up · will do`

## ✅ After you speak
- The blocker formula = **be honest + name the exact problem + ask**:
  *"I'm a little stuck — the tests need a database setup I don't have. What should I do?"*
- 💡 **"to be honest"** — an honest conversation opener with your team. Safe and professional.
- 💡 **"Will do."** = "I will do it" — the perfect short answer to instructions. *"Will do, thank you."*
- 💡 **"Give it a try."** = "try it" (very common). *"I'll give it a try first."*
- 🎙️ Play `standup-03` and answer. Then say YOUR real current blocker with the formula.
