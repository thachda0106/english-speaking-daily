# Day 4 · Conversation 1 — The Stand-up Format

## 🎬 Situation
Your first morning stand-up. The stand-up has exactly 3 questions you must answer: **What did you do yesterday? What will you do today? Any blockers?** Learn this shape — it's the same in every company on earth.

## 🗣️ Dialogue — read out loud (both roles), then play the audio and answer

> **Team lead:** Good morning, everyone. Let's start the stand-up. Thach, do you want to start?

> **You:** Sure. Yesterday I read the code and set up the project on my computer. It took me most of the day, but now everything runs.

> **Team lead:** Great. What are you planning to do today?

> **You:** Today I want to pick up a small task from the board — maybe a bug fix, so I can learn the codebase.

> **Team lead:** Good idea. Do you have any blockers?

> **You:** No blockers, but I still have a few questions about the deployment process. I can ask after the meeting.

> **Team lead:** Perfect. Let's move on.

## 🧠 Your active vocabulary — all words you already know
`stand-up · start · yesterday · read · code · set up · project · computer · day · runs · planning · today · pick up · small · task · board · bug fix · learn · codebase · blockers · questions · deployment · process · meeting · move on`

## ✅ After you speak
- The stand-up answer = **3 sentences, 3 shapes**:
  1. **Yesterday** → *"Yesterday I…"* (past tense!)
  2. **Today** → *"Today I want to / I'm going to…"*
  3. **Blockers** → *"No blockers, but…"* or *"I'm blocked on…"*
- 💡 **"pick up a task"** = choose/start a task. *"I'll pick up this bug today."* (common in every scrum team)
- 💡 **"move on"** = continue to the next person. *"Let's move on to the next item."*
- 🎙️ Play `standup-01` and answer. Then say your FULL 3-sentence stand-up from memory, with YOUR real tasks.
