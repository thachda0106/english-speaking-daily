# Day 10 · Conversation 4 — When You Don't Know

## 🎬 Situation
They ask about something you have never used. This is the moment most candidates fail — they either freeze or start inventing. The skill is saying **"I don't know"** without losing your confidence.

## 🗣️ Dialogue — read out loud (both roles), then play the audio and answer

> **Interviewer:** How would you use Kafka in a system like ours?

> **You:** Honestly, I've only read about Kafka. I haven't used it in real work yet.

> **Interviewer:** Okay. So what would you do if you needed to use it?

> **You:** I'd start by understanding the problem it solves. I know the general idea — it's for sending events between services, so they don't have to know about each other.

> **Interviewer:** That's right. Would you be able to learn it quickly?

> **You:** I think so. When I joined my current company, I had to learn a system I'd never used, and I learned it in a few weeks. The pattern was always the same — read, then build something small, then get feedback from the team.

> **Interviewer:** That's a good answer. I'd rather hear "I don't know" than a guess.

## 🧠 Your active vocabulary — all words you already know
`only · read · about · used · real work · understand · problem · solves · general idea · sending · events · services · right · learn · quickly · think · joined · current company · never used · few weeks · pattern · same · build · small · feedback · team · better · guess`

## ✅ After you speak
- The don't-know formula = **honest + what I do know + how I'd learn**:
  *"Honestly, I've only read about Kafka. I know the general idea, and I'd start by understanding the problem it solves. I learned a new system in a few weeks at my current company, so I'd be able to learn it."*
- 💡 **"I've only read about it."** — honest, professional, and it still sounds senior. Better than *"I know Kafka"* (a lie they will test) and better than silence.
- 💡 **"The pattern was always the same — read, then build something small, then get feedback."** — 🎯 **this is your strongest answer in the whole course.** It proves you can learn *anything*, using a method you have actually used. Say it in every interview where you don't know something.
- 💡 **"That's a good answer."** — the interviewer is telling you it was fine. Listen for it; it means you passed.
- 🎙️ Play `interviewer-04` and answer. **Today: say "The pattern was always the same — read, build something small, get feedback" out loud 3 times.**
- 🧠 **Your mental model:** an interview is not a test of what you know. It is a test of **how you behave when you don't know.** Honesty + a learning method beats a confident guess every single time.
